# Códice de la Estabilidad

Web narrativa en Astro y TailwindCSS basada en los documentos de lore de `Historias/`.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Estructura

- `src/pages/`: páginas `/`, `/historia` y `/dogma`.
- `src/components/`: componentes reutilizables de UI.
- `src/layouts/BaseLayout.astro`: layout común con SEO básico, navbar y footer.
- `src/data/lore.ts`: contenido estructurado del lore.
- `src/styles/global.css`: fuentes, tokens visuales, textura y utilidades globales.
- `public/favicon.svg`: sello visual del proyecto.
